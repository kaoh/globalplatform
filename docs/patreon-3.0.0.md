# GPShell 3.0.0

## Creator profile

Maintainer of GlobalPlatform and GPShell, an open-source C library and command-line toolkit for managing GlobalPlatform smart cards. The project covers secure channels, Java Card application lifecycle management, PC/SC connectivity, and practical tools for developers and integrators. Sponsorship helps fund maintenance, release engineering, documentation, hardware, and interoperability testing.

## Release post

### GPShell 3.0.0 is available

GPShell 3.0.0 is the next stable release of the GlobalPlatform library and its command-line tools. It makes GPShell3 the preferred command-line interface while retaining the original GPShell for existing scripts and workflows.

The release includes secure-channel support for SCP01, SCP02, SCP03, and SCP11a; GlobalPlatform 2.1.1 card-management operations; delegated management with DAP receipts; and support for AES, DES/3DES, RSA, and ECC keys. GPShell3 provides the current scripting interface for card recognition, CPLC and data retrieval, application and key management, raw PC/SC access, and extended APDUs.

The Windows release now also provides signed shared-library SDK archives for x86 and x64. They include CMake package metadata, the PC/SC connection plugin, headers, runtime dependencies, and a small CMake consumer example.

Release notes and downloads are available at [GitHub Releases](https://github.com/kaoh/globalplatform/releases). The current manuals and API reference are published at [kaoh.github.io/globalplatform](https://kaoh.github.io/globalplatform/).

The GPShell walkthrough videos are available in the [GPShell YouTube playlist](https://www.youtube.com/watch?v=igqlIvuOB5o&list=PLg46pyBZ2z-wF8acSL1nWvWFU0WPmhwlD).

Thank you for supporting the work that keeps GlobalPlatform and GPShell available to smart-card developers and integrators.
